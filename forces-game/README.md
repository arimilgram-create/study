# Inertia Quest

A study game for the **Forces, Free Body Diagrams and First Law** quiz review.
Each station is one review question turned into a mini-game:

| Station | Review question | What you do |
|---|---|---|
| Mass or Weight? | Q1 | Speed-sort clues, then calculate F<sub>g</sub> = mg |
| Banana Scale | Q2 | Build the FBD, calculate weight, run a live force-probe graph |
| FBD Hangar | Q3 | Build FBDs for 3 planes (parked, taxiing, cruising) |
| Moon Breakout | Q4 | Cut Earth's gravity and aim the Moon at a satellite |
| Planet Slope Lab | Q5 | Weight vs. mass graphs on 4 worlds; slope = g |
| Crash Test Dummy | Q6 | Crash a car with and without a seatbelt |
| Franky's Wagon | Q7 | Tug lab, FBD, friction and net force calculations |
| Inertia or Force? | Q8 | Myth-busting sort round |
| Terry's Heavy Box | Q9 | Lift a box onto a shelf without smashing it |
| Newton's Final Exam | All | 10 random timed questions, 3 hearts |

Open `index.html` in a browser to play. Progress (XP, stars) is saved in the browser.
